# Open Rig roadmap

Updated 2026-09-25. This is the agent-facing ledger; the detailed Explorer
acceptance plan is [`docs/plans/explorer-ide.md`](docs/plans/explorer-ide.md).

## Current baseline

- **Harness:** OpenCode v2 on Ubuntu GNOME/Wayland.
- **Active:** twelve v2 plugin packages, bounded MCP launchers, 19 skills
  (including `development-conventions`, `agent-orchestration`, and
  `session-context`), and the v2
  setup/deployment/health checks.
- **Explorer:** active Phase 1 editor core with explicit saves and safety guards.
- **Fallback:** provider-wide quota routing recognizes Codex, DeepSeek balance,
  and OpenCode Zen free/Go exhaustion; configured tiers form a bounded cyclic
  path, while runtime behavior still depends on provider availability.
- **Provider usage:** the current server/source pipeline resolves authoritative
  provider, integration, connection, runtime-readiness, and metadata-only
  activity state and exposes sanitized rows through `provider.usage.snapshot`.
  Focused package evidence covers working-provider visibility, OpenCode Zen
  readiness without a quota adapter, disabled/absent suppression, and the
  inclusive two-hour recent-activity boundary. The retained 2026-09-22 text
  capture showed `OpenAI READY · Weekly: 28% left`, `OpenCode Zen OFFLINE`,
  and Ingenium `OFFLINE`; those offline-row observations are superseded and do
  not accept the corrected visibility contract. Fresh deployed/live evidence
  for the correction remains in progress. At 80 and 60 columns native OpenCode
  hides the sidebar, so no provider-row visibility is claimed there. The
  periodic server poll defaults to 60 seconds and is never shorter than 30
  seconds; RPC/manual refresh is server-throttled, credential/provider/
  integration events may force an immediate refresh, and concurrent requests
  coalesce. Native privileged-host, isolated WSL full apply, and bootstrap
  live-apply boundaries remain explicit.
- **Ponytail:** official `4.10.0` content runs through the local v2 adapter,
  which defines six commands and six skills; the updater/timer are retired.
  The current selected-location runtime reports Ponytail active (95/95 plugins);
  the cause of the earlier `MODULE_NOT_FOUND` report remains unknown.
- **Agent orchestration:** source/package hooks enforce background-only child
  launches, a project-configurable `1..10` cap as the sole concurrency
  admission gate, diagnostic-only host/cgroup estimates, nested-agent denial,
  and policy injection from `opencode.json` plugin options. The globally
  ingestible plugin must not impose Open Rig agent/model allowlists on unrelated
  repositories; consuming repositories retain their own agent/model choices.
  Omitted models resolve through the configured agent after a clean
  shared-service restart.
- **Not claimed:** LSP, formatter integration, full IDE parity, or native
  in-TUI browser embedding.
